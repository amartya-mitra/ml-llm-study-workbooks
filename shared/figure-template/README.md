# Figure template

Every figure in this project is generated by a small, self-contained
Python script that writes an SVG directly (no external plotting/diagram
dependency required, since this environment has no `pip`). This keeps
figures:

- reproducible from source control alone
- editable by changing a script, not a binary
- consistent with `config/visual-style.yaml` (palette, arrow semantics,
  typography)

## Convention

- Figure-generating scripts live in `figures/source/<figure_id>.py`.
- Each script's `main()` writes its rendered SVG to
  `figures/rendered/<figure_id>.svg`.
- Each script must load `config/visual-style.yaml` for colors rather than
  hardcoding hex values, so a future palette change propagates everywhere.
- Each script should print, as a comment or docstring, the one-line "what
  to notice" caption that belongs in the chapter that uses it.

## Starting point

Copy `figure_template.py` in this directory as a starting point for a new
figure. See `figures/source/kv_cache_demo.py` for a complete worked
example (the Stage 6 demonstration figure).
